# 纯 TV 项目收敛实施记录

用户于 2026-10-29 确认不再维护手机端，并授权实施。现有媒体库、存储、弹幕、字幕、播放会话及 Media3/mpv 内核继续维护。旧文档中的手机兼容要求由本次产品决定取代，历史测试结果保留。

## 实施与验收

1. 统一启动与界面：普通和 Leanback 入口均进入 TV 主壳，兼容旧组件名；删除手机导航和分页分支。验证：Manifest、编译、启动和 DPAD 返回路径。
2. TV 行为默认化：共享列表、设置、弹窗、焦点样式不再依赖系统报告电视模式。验证：非 TV UI mode 环境中的遥控导航及设置持久化。
3. 精简播放器：删除手机触屏手势、传感器旋转和专属设置，保留遥控 seek 反馈及媒体方向/比例。mpv 固定 SurfaceView、mediacodec_embed、mediacodec，处理 Surface 解绑/重绑和旧配置。验证：JVM、原生编译、播放与重入。
4. 集成检查：Debug/Release/test APK、JVM、lint、模块/播放边界检查；纯 DPAD 完成启动、浏览、设置、播放、返回。实机 TV 画质效果与硬件解码覆盖须明确区分于 AVD 验证。

## 已知边界

- Media3 渲染器配置保持独立；移除 mpv 视频 GPU 输出不影响独立 libass GPU 字幕叠加层。
- mpv 直出当前不支持内嵌位图字幕；明确提示并保留 Media3 选择，不静默回退到 GPU 视频输出。
- 不新增后台/PIP 托管能力，不实施此前延期的 Media3/libass 改造。
- 保持 `leanback required=false`，兼容普通 Android 盒子；产品 TV 交互不以硬件类别为开关。

## 执行状态

代码实施和本地验证已完成（2026-10-29），未创建 Git 提交。普通和 Leanback launcher 均进入 TV 页面；共享 UI 使用 TV 默认行为，不再维护手机端分支。

mpv 视频固定使用原生 SurfaceView、`vo=mediacodec_embed`、`hwdec=mediacodec`，删除视频 GPU/TextureView 路径和输出选项，不允许软件回退。保留独立 libass 字幕叠加层。有效 Surface 到来前不加载视频；解绑依次停用视频、清空输出和窗口引用，重绑恢复固定输出与视频轨。解绑/重绑失败上报并停止，旧实例回调按 generation 丢弃；正常停止不误报播放错误。旧手机设置及 mpv 输出配置在启动时清理。

## 验证中发现与修复

- 原生帧测试发现 `vid=no → auto` 重绑会使暂停位置从 0 漂移到 500ms；重绑时恢复暂停的可寻址时间，使用精确 seek。测试改为先停在非零位置，再检查新 Surface 帧、暂停进度、恢复、换源和释放；修复版首次通过 2 项真实 JNI 测试。
- mpv 视频硬解失败可关闭视频链而继续播音频。增加初始化和已建立视频输出丢失的检查，主动解绑、停止和换源重置检测状态；不支持的视频伴随 AAC 的实际测试已验证错误回传。
- 普通系统模式下，系统栏遮挡 TV 标题与首项。共享 Activity 默认隐藏系统栏并清除旧 fits 状态，已通过截图确认设置标题完整。
- 弹窗单次 BACK 用例失败时，诊断确认文字选项已获得焦点但输入法自动显示；弹窗初始化改为禁止自动弹出输入法，保留窗口调整模式与显式编辑入口。最终设备回归通过，诊断读回 `imeVisible=false`，一次 BACK 即关闭弹窗，未降低断言。
- 初始新增测试 API 不存在、已取消限定资源的旧一致性测试、PowerShell 参数解析及 Gradle UTP 离线依赖分别导致失败；已修复测试和命令，设备用例改用 ADB 直接运行已编译 APK。首次沙箱启动 AVD 被锁文件权限阻止，改用获准的只读实例。
- 初始竖屏 AVD 与四列网格的 TV 测试条件不符，且缺少长视频 fixture；补齐 fixture 并将本次实例临时设为 1920×1080 / 160 dpi。系统 UI mode 始终保持普通模式 `0x11`，未伪造 TV feature。

## 尚未验收的范围

- 物理 TV 的画面设置/PQ 效果、HDR/杜比视界及不同 SoC 的解码兼容性，不能由此 AVD 的帧测试推断已通过。
- 复杂字幕及内嵌位图字幕的完整媒体矩阵仍需实机验收；mpv 位图字幕限制按上文处理，使用 Media3。
- 暂停重绑位置恢复已在可 seek 的本地媒体验证；非 seekable 流不在精确位置恢复的通过范围内。真实网络、多源连续播放等既有验收缺口仍由各自记录维护。
