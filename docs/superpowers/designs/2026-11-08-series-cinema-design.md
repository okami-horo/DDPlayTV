# 剧集详情大画面设计提案

日期：2026-11-08。状态：**网页提案待用户确认；原生未实施。** 用户要求先用 Web 展示新 UI，确认后实施。当前应用仍以 2026-11-01 已选 B 为基线；本提案的 A/B 编号仅属于本次评审。

## 目标与范围

将首页的大画面、文字叠加与渐隐视觉延续到作品详情，改善当前暗背景、小幅倾斜海报和上下分块造成的疏离感。保留续播、完整简介、资料管理、季切换、分集进度、实际文件版本及返回原入口的能力。

本轮仅修改 `document/prototypes/tv-ui/` 的网页与相关设计记录。没有修改 Android 布局、Kotlin、数据与播放流程，没有启动 Gradle、打包、安装或操作实体电视。

## 预览与候选

在项目根目录运行：

```powershell
node document/prototypes/tv-ui/server.cjs 4191
```

打开 `http://127.0.0.1:4191/series-detail-prototype.html?review=cinema&variant=hero`。

| 参数 | 结构与取舍 | 当前决策 |
| --- | --- | --- |
| `variant=hero` | A「全景剧场」：右侧清晰作品画面、左侧标题与续播、下方横向选集；背景连续渐隐，普通字号首屏四张完整卡与后续提示 | 推荐，待用户确认 |
| `variant=split` | B「画面与列表」：左侧作品与主操作，右侧纵向剧集列表；适合持续上下选集，作品画面的完整度较低 | 备选，未选定 |
| `variant=current` | 现状结构重建：右侧倾斜小海报与独立横向剧集区，用相同示例资料比较比例 | 对照，非新采集的原生截图 |

旧入口 `series-detail-prototype.html?variant=B` 保留原先的 2026-11-01 设计，只有 `review=cinema` 才进入新提案。底部评审切换条不属于原生页面。切换条获得焦点时左右切方案；画面内部方向键导航、Enter 确认、Esc 返回。可选 100% / 130% 字号及全屏；URL 保存方案和评审场景，业务状态仅在内存中。

## A 的具体设计

- 以 1440×810 逻辑画布表达 960×540dp 的比例。页头保留品牌和「作品详情」，不加入页面内返回按钮。
- 大画面铺到顶部及选集标题背后。左侧渐变保护文字对比度，底部渐隐到页面底色；取消常规状态的独立倾斜海报。
- 标题使用完整作品名，允许换行；年份、类型次之，简介最多两行并保留完整阅读入口。主续播突出，管理资料降低视觉权重。
- 常规首屏四张 300×169px 图区的剧集卡，留出第五张的一部分表达横向延续。图片与卡片文本保持共同的作品顺序。
- 焦点落在图片边缘；「上次观看」与文件进度独立保留，不把焦点当作播放选择或已观看状态。
- 多季在剧集标题同行选择；切季只改变浏览区，主续播仍绑定原历史季集。
- 130% 字号及超长标题使用内容自然增高和焦点滚动，不把完整标题缩小或截断来硬塞首屏。此状态不承诺所有内容同时可见。
- 仅有竖海报时显示正置海报和低干扰氛围背景；无图使用中性色渐变；缺少分集图片时保留集号占位。

## 页面与状态覆盖

下列页面均在同一网页路由，使用 `state=` 切换。**所有原生实现、原生构建/测试、实体电视与用户视觉验收均未开始。**

| 编号 | 场景 / 参数 | 网页设计与验证要求 |
| --- | --- | --- |
| SC01 | `normal` / `fresh` | 有历史与无历史的主动作、完整四卡、焦点向下选集 |
| SC02 | `seasons` | 常规季 / 第二季 / 特别篇；切季不改变主续播目标 |
| SC03 | `long`、`font=1.3` | 完整长标题、内容增高、焦点滚动；主动作与卡片可达 |
| SC04 | `poster` / `noart` / `nostill` | 竖海报回退、无图背景、分集占位，不依赖全部素材齐全 |
| SC05 | `initial` | 首次读取与骨架，不伪装成空库或允许播放 |
| SC06 | `empty` | 保留作品资料，媒体库入口可达并可返回 |
| SC07 | `missing` | 原续播禁用，默认可用集；版本弹窗跳过不可用原文件，保留其 42% 进度 |
| SC08 | `error` | 来源失败常驻提示，重试仍失败时不显示播放成功 |
| SC09 | `unknown` | 显示 10:08，隐藏不可靠百分比与进度条 |
| SC10 | 第三集 / `movie` | 实际版本选择、取消恢复焦点；另一版本从自己的起点开始 |
| SC11 | 完整简介 / 管理资料 | 弹层可读，Esc 回到调用控件；管理页面只表达原有流程衔接 |
| SC12 | 横向滚动 / 分栏列表 / 返回 | 卡片完整进入可视区，回到主操作；顶层 Esc 只说明返回语义，不导航到真实页面 |
| SC13 | 评审壳 / URL / 旧入口 | 切换方案可用、刷新恢复方案、窄浏览器适配；旧 B 入口不受影响 |

## 素材与实施边界

[素材说明](../../../document/prototypes/tv-ui/assets/series-cinema/README.md)列出官方图片来源与下载日期。大画面示例裁切自官方无字竖构图主视觉，并不是当前 TMDB 横图的成功加载证据。原生应读取作品真实 `backdrop`；只有 `poster` 时按回退稿展示，不假设每部作品都能套用本示例的人物位置。分集配图、数量、进度和电影场景均是排版夹具。

未来实施映射：`activity_metadata_detail.xml`、`MetadataDetailActivity`、`item_metadata_episode.xml` 及直接相关 drawable。保持现有数据身份、整剧跨季队列、文件独立进度、历史恢复和管理资料行为；不把示例内容、官方网站图片或网页状态带进生产应用。
