## 维护方式

- `designs/` 保存仍有约束价值的设计决策；实现变化时修正状态与失效假设，避免变成另一套实现说明。
- `plans/` 保存正在执行或仍承担原始验证证据的账本，明确未完成项；不删除有价值的失败记录和验收限制。
- `archive/` 保存精简后的历史决策与有出处的遗留事项，不保存原始聊天、工具输出或可从 Git 恢复的大段旧代码。
- 文档整理不改变任务验收状态。后续测试或用户验收发生后，再更新相应账本与导航。
