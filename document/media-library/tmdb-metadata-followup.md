# TMDB 媒体库与自动识别

更新：2026-11-01。播放触发自动识别已接入，当前构建、测试与验收边界见[实施账本 AM01–AM13](../../docs/superpowers/plans/2026-11-01-playback-auto-metadata.md)。[首期记录](../../docs/superpowers/plans/2026-10-31-tmdb-media-library.md)保留原始迁移、真实 API/图片与 Cinema 证据，不代替本轮验证。

## 使用方式

- 正常播放视频即可触发后台识别，不需要先设置电影/剧集目录类型。播放与资料请求独立；电影只处理当前文件，剧集额外检查当前物理目录一层的同剧视频。
- 首页按作品汇总，详情只提供实际发现并关联的文件。未观看集不会生成观看记录；当前集、来源和进度仍按真实文件保存。
- 从作品详情的资料入口，或“已入库作品 → 待识别文件”进入“资料与识别问题”。可以重新识别或刷新资料，不再搜索候选、手选季集或预览人工目录映射。
- **重新识别**重新读取文件并核对归属，成功后才替换旧关联；可解除该文件的旧忽略状态。**刷新资料**保持作品身份，只更新简介、图片和已有季集文本。
- “资料与任务”区分播放触发和主动目录扫描，显示入库、未识别、失败数量，支持取消及原范围重试。仍可在来源目录主动扫描；递归范围在确认时说明。
- 弹弹play/local 弹幕与字幕绑定是独立能力，播放器中的搜索和本地选择入口保持不变。

## 命名与重试

支持以下已测试形式：

| 文件名 | 行为 |
| --- | --- |
| `片名 (2024).mkv`、`片名.mkv` | 类型、标题和可用年份证据唯一时入库；没有年份不会直接拒绝 |
| `剧名 S01E03.mkv`、`剧名.S01.E03.1080p.mkv`、`剧名_1x03.mkv` | 归一到明确季集并核验 TMDB |
| `剧名 S00E02.mkv`、`剧名 S01E01-E02.mkv` | 支持特别篇和合并集；合并文件只有一份播放进度 |
| `[字幕组] 剧名 - 13 [1080p].mkv` | 能提取连续集号，但不擅自换算季度，显示具体原因 |
| `剧名 S01E03 [tmdb-tv-123].mkv` | 可选明确 ID 帮助消歧，仍核验类型与季集 |

同名歧义、候选分页预算不足和无结果都保留原文件入口，不取搜索第一条。已有有效人工关联/忽略结果保留。文件名或身份标记变化会使旧识别尝试失效；临时服务错误保存时间，五分钟内抑制自动重复请求，手动重试可绕过。再次播放同剧时，完整目录快照最多复用 60 秒，之后可发现新增集。

## 来源与兼容边界

- 首批支持 **本地、SAF、SMB、WebDAV**。本地定向读取同级视频，包含尚未进入视频索引的文件；不自动递归全盘。
- SAF 父目录只使用可信浏览上下文或已核验目录，不截取文档 URI 猜测；无法确认时仅处理当前文件并显示同目录发现未完成。
- 自动同剧发现不执行整目录缺失清理，网络/部分读取失败保留已经保存的结果。其他协议仍可播放，任务页明确提示暂不支持自动入库。
- 无稳定文件 ID 的路径改名无法可靠继承旧历史；不会仅凭大小、相似名称或同一个 TMDB ID 合并进度。
- 任务仅在应用进程内运行，进程退出后按下一次播放/重试重新读取所需范围；不承诺常驻后台执行。
- Room 20→21 为增量迁移，新增尝试时间与自动任务的触发文件信息，保留旧手工绑定、忽略和播放历史。
- 资料语言固定中文，缺失文本回退原名/英文；成人搜索关闭。令牌由构建注入，无电视输入步骤。NFO、自选图片、跨目录收集、自动重命名和新增在线资料源不在本轮范围。
