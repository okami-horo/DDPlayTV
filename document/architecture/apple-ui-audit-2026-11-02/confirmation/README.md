整理日期：2026-11-02。对应 [Apple 风格审查报告](../../apple-ui-audit-2026-11-02.md)。

打开 [截图图库](index.html)，按 A01–A07 或截图来源筛选；点击图片放大，橙框可隐藏，也可打开原图。共 40 张不同截图：20 张历史原生图、20 张 2026-11-02 渲染的原型图。

原生图来自既有本地验证，**不是本次抓取或当前电视实拍**。其中 FTP、WebDAV 滚动后的两张错误状态图在这次整理中补充收录；原审查的 64 个原型视图与 20 张历史原生抽样统计保持原义。原型只代表设计稿，旧返回/关闭按钮等被后续产品决策覆盖的内容不据此认定为当前缺陷。

橙框标出的是待确认位置，尚未据此修改 UI。A02、A03、A05、A06 包含视觉偏好和组织方式建议；无需将所有标框都视为必须修复的功能问题。图库没有恢复已撤下入口，也没有重新验证账户服务、原生运行、DPAD 或电视画面。
